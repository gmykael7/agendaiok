# AgendAI v1.15.10 — Tipografia Montserrat

## Alterações
- Toda a interface do AgendAI agora usa a família Montserrat.
- Aplicado ao painel administrativo, site público, autenticação, Super Admin, produtos, modais e modo TV.
- Pesos de 100 a 900 e itálico carregados via Google Fonts.
- A classe Tailwind `font-sans` também foi redefinida para Montserrat, garantindo consistência em toda a aplicação.
- Mantido fallback para fontes nativas do sistema caso o Google Fonts não carregue.

## Banco de dados
- Nenhuma alteração de banco.
